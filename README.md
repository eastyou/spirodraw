# spirodraw

[![CI](https://github.com/eastyou/spirodraw/actions/workflows/ci.yml/badge.svg)](https://github.com/eastyou/spirodraw/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.9%2B-brightgreen.svg)](pyproject.toml)

用参数方程画万花尺：生成 A4 纵向、可直接打印的描摹画册，每条曲线附上 R / r / d 参数表，学生照着参数就能用真实万花尺复现。**零第三方依赖，纯标准库，离线可用。**

## 特性

- **数学正确**：严格按内摆线（hypotrochoid）参数方程采样，末点与首点在 `1e-9` 内闭合
- **周期精确**：按 `r / gcd(R, r)` 计算闭合圈数，支持整数与最多 3 位小数的 R、r
- **一排两图**：每页 2 条曲线，每条独占一张卡片和独立 `viewBox`，不裁切、不叠线
- **参数可查**：卡片下方列出 R、r、d、闭合圈数、颜色与笔距比，最后一页汇总全部参数
- **自动选参**：内置候选池 + 视觉距离校验，1~12 条曲线不重复、不相似，容易分辨
- **种子复现**：`--seed` 默认 42，同一颗种子生成完全相同的画册
- **中文校验**：参数越界、非整数、曲线无法闭合都会给出中文提示，退出码 2
- **打印友好**：A4 纵向、`@page` 无页边距、屏幕自适应不横向溢出
- **110 个单元测试**：覆盖公式抽样、闭合点、周期、参数去重、种子复现、SVG 边界、转义与命令行

## 数学

定圆半径 R、动圆半径 r、笔距 d，笔尖坐标为：

```text
x(t) = (R − r)·cos t + d·cos((R − r)/r · t)
y(t) = (R − r)·sin t − d·sin((R − r)/r · t)
```

约束：`R > r > 0`、`0 < d ≤ r`，且曲线不能退化成点或直线。

闭合周期：令 `g = gcd(R, r)`，动圆需要转 `q = r / g` 圈才回到起点。采样点数为 `q × 每圈采样数 + 1`，最后一点直接取首点，保证严格重合。例如 `R=9, r=6` 时 `g=3, q=2`，曲线 2 圈闭合。

小数半径会先按共同倍率放大成整数再求最大公约数，例如 `R=8.4, r=2.4` 放大为 `84` 与 `24`，最大公约数 `12`，闭合圈数 `2`。

```bash
pip install spirodraw
```

```bash
python -m spirodraw --help
```

## 用法

```bash
python -m spirodraw --curves 6 --seed 42 --title 万花尺描摹画册 -o examples/万花尺画册.html
```

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--curves` | 曲线数量，1~12 的整数 | `6` |
| `--seed` | 随机种子，同种子结果完全一致 | `42` |
| `--title` | 画册标题，最多 40 个字符 | `万花尺描摹画册` |
| `-o, --output` | 输出 HTML 路径 | `万花尺画册.html` |

退出码：`0` 成功；`1` 写入文件失败；`2` 参数错误或曲线无法闭合。

## 默认画册参数

`--curves 6 --seed 42` 生成的 6 组参数（每圈采样 180 点）：

| 序号 | 定圆 R | 动圆 r | 笔距 d | d/r | 闭合圈数 | 采样点 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01 | 24 | 2 | 2 | 1.00 | 1 | 181 | 靛蓝 |
| 02 | 9 | 4 | 3.6 | 0.90 | 4 | 721 | 朱红 |
| 03 | 27 | 5 | 5 | 1.00 | 5 | 901 | 松绿 |
| 04 | 34 | 5 | 2.5 | 0.50 | 5 | 901 | 紫罗兰 |
| 05 | 37 | 5 | 3.5 | 0.70 | 5 | 901 | 赭石 |
| 06 | 28 | 9 | 9 | 1.00 | 9 | 1621 | 孔雀蓝 |

每条曲线独占一张卡片，参数表就在图形正下方。裁下卡片或整页打印都可以直接描摹。

## 打印与描摹

用浏览器打开生成的 HTML，按 `Ctrl/Cmd + P`：

- 纸张：A4 纵向
- 边距：无 / 默认
- 缩放：100%
- 勾选「背景图形」，彩色圆点和卡片边框才会打印

描摹建议：

1. 打印后用半透明纸覆盖，先用铅笔轻描曲线骨架。
2. 再用 0.5 mm 彩色笔沿铅笔线描一遍，粗细均匀、运笔放慢。
3. 曲线交叉处不要停顿，保持手腕悬空、整臂带动。
4. 想画得更大，把卡片上的 R、r、d 同比例放大后画到更大的纸上。

## 自制万花尺

真实万花尺由定圆、动圆和笔孔组成，和画册里的参数一一对应：

1. 用硬纸板剪两个圆，半径分别是 R 和 r（保持卡片上的比例，可整体放大）。
2. 在动圆上距圆心 d 处扎一个笔孔，`d ≤ r`。
3. 定圆固定在纸上，动圆放进定圆内侧，两圆内切。
4. 笔尖插入小孔，让动圆沿定圆内壁无滑动地滚动。
5. 动圆滚满「闭合圈数」所示的圈数后，曲线正好回到起点。
6. 沿曲线用彩笔描摹，即可得到画册上相同的图案。

形状只取决于 `R/r` 与 `d/r` 两个比值；整体放大不会改变图案，只会改变作品尺寸。

## 项目结构

```text
spirodraw/
├── spirodraw/
│   ├── model.py    # 参数校验、闭合周期、参数方程采样、候选池
│   ├── render.py   # A4 排版、SVG 生成、参数表与自制说明页
│   ├── cli.py      # 命令行入口与中文错误提示
│   ├── __main__.py # python -m spirodraw
│   └── __init__.py # 公共 API
├── tests/          # 110 个单元测试
├── examples/       # 示例画册（万花尺画册.html）
└── .github/workflows/ci.yml
```
